# Weather-app-using-API-and-PyQt5
This repository contains a Python program that uses Open Weather and Python's built in UI tool PyQt5 to show the weather in cities around the world. The user can input the names of cities from around the world and it will display the temperature and a small description of weather conditions and an emoji giving the user a visual reference of the weather.

# How to Run the Code
If you haven't already, download and install Python (https://www.python.org/downloads/) as well as any Python IDE ((I used Pycharm to code the program) https://www.jetbrains.com/pycharm/download/?section=windows) so you can run the program from the software. Before you can run the code however, two Python extensions need to be istalled or else the program will return an error and will fail to run. In the command prompt of the IDE or through the command prompt on your system, type "pip install requests" and "pip intsall PyQt5". After they have been installed, the Weather App should successfully run.
